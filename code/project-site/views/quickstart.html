Quickstart – How to Run BoardApp

  1. Clone the repository: 
    git clone https://github.com/PoolyDsXForce/boardapp.git
  2. Navigate into the project folder: 
    cd boardapp
  3. Build the project using Maven: 
    mvn clean install
  4. Run the application: 
    mvn javafx:run
  5. The JavaFX window will appear showing “Hello JavaFX!”.
