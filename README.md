# BoardApp – JavaFX Application

This project is a simple JavaFX application created for COMP 2500. The current version of the application displays a window with the text “Hello JavaFX!”. This serves as the foundation for future assignments where additional features will be added.

---

## 📦 Project Structure

boardapp/
├── src/
│   └── main/
│       ├── java/
│       │   └── (JavaFX source files)
│       └── resources/
├── pom.xml
└── README.md

---

## 🚀 How to Run the Application

### 1. Build the project
Make sure Maven is installed, then run:

mvn clean install

### 2. Launch the JavaFX application

mvn javafx:run

### 3. Expected Output
A JavaFX window will appear showing:

Hello JavaFX!

This confirms the application is running correctly.
